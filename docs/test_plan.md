# План тестирования geometric_lib

## 1. Цели и задачи тестирования

**Цель:** удостовериться, что все функции вычисления площади и периметра фигур возвращают правильные значения.

**Задачи:**
- написать unit-тесты для каждой из функций;
- проверить обычные, дробные и нулевые значения;
- автоматизировать запуск тестов.

## 2. Описание тестируемого продукта

geometric_lib — библиотека на Python для вычисления площади и периметра геометрических фигур:
- `circle.py` — круг: `area(r)`, `perimeter(r)`;
- `square.py` — квадрат: `area(a)`, `perimeter(a)`;
- `rectangle.py` — прямоугольник: `area(a, b)`, `perimeter(a, b)`;
- `triangle.py` — треугольник: `area(a, h)`, `perimeter(a, b, c)`.

Требование к продукту: функции должны возвращать значения, вычисленные по математическим формулам.

## 3. Область тестирования

Тестируются все 8 функций из 4 модулей. Обработку некорректных входных данных (отрицательные числа, строки) не тестируем, так как библиотека её не предусматривает.

## 4. Стратегия тестирования

- **Вид тестирования:** функциональное модульное (unit) тестирование.
- **Инструмент:** стандартный модуль Python `unittest`.
- **Метод:** чёрный ящик — для набора входных данных заранее вычисляется ожидаемый результат и сравнивается с результатом функции.
- **Проверяемые значения:** типичные, нулевые и дробные.
- **Дробные результаты** (с использованием числа π) сравниваются с точностью до 7 знаков после запятой (`assertAlmostEqual`).
- **Запуск:** `python -m unittest -v`

## 5. Критерии приёмки

- для каждой функции есть хотя бы один тест;
- все тесты проходят успешно;
- найденные дефекты исправлены, и после исправления тесты проходят.

## 6. Ожидаемые результаты

- набор тестов в репозитории (файлы `test_*.py`);
- отчёт о запуске тестов со статусом OK или FAILED;
- список найденных дефектов;
- метрика качества — доля успешно пройденных тестов.
