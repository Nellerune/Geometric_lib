# Общее описание решения
- Geometric lib содержит формулы площади и периметра для разных фигур: круга,прямоугольника,круга и квадрата

# Формулы

## Площадь
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = a*h/2

## Периметр
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P=a+b+c

# Описание функций

## 1. Круг (circle.py) 
area(r): Принимает радиус r, возвращает площадь круга.
- Пример вызова: area(5) возвращает 78.53981633974483
- perimeter(r): Принимает радиус r, возвращает длину окружности.
- Пример вызова: perimeter(5) возвращает 31.41592653589793

## 2. Квадрат (square.py)
- area(a): Принимает длину стороны квадрата a, возвращает его площадь.
- Пример вызова: area(4) возвращает 16
- perimeter(a): Принимает длину стороны a, возвращает периметр квадрата.
- Пример вызова: perimeter(4) возвращает 16

## 3. Прямоугольник (rectangle.py)
- area(a, b): Принимает длины сторон a и b, возвращает площадь прямоугольника.
- Пример вызова: area(4, 5) возвращает 20
- perimeter(a, b): Принимает длины сторон a и b, возвращает периметр.
- Пример вызова: perimeter(4, 5) возвращает 18

## 4. Треугольник (triangle.py)
- area(a, h): Принимает длину стороны a и высоту h, проведённую на эту a, возвращает площадь.
- Пример вызова: area(4, 5) возвращает 10
- perimeter(a, b, c): Принимает длины трех сторон треугольника, возвращает его периметр.
- Пример вызова: perimeter(3, 4, 5) возвращает 12
